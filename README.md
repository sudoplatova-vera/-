# ВЕРСУ: сайт-визитка

Статическая версия сайта Веры Судоплатовой, подготовленная для GitHub Pages.

## Как опубликовать

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `.nojekyll` и папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.

После публикации GitHub покажет адрес сайта в разделе Pages.

## Структура

- `index.html` — содержание страницы;
- `styles.css` — оформление и адаптация под мобильные устройства;
- `assets/versu-mark.png` — фирменный знак;
- `assets/vera-sudoplatova.jpg` — фотография.

Контакты, тексты и ссылки можно менять непосредственно в `index.html`.
